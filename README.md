## 📖 Project Overview

The Ethical Leadership Survey is an interactive web application designed to explore how individuals respond to ethical dilemmas in leadership situations.

Participants are presented with three scenarios requiring them to make decisions involving ethical judgment, integrity, accountability, and responsibility.

Based on their choices, the application calculates an ethical leadership score and displays an animated result.

The project demonstrates how technology can make ethical leadership education more interactive and engaging.

## 🎯 Project Objectives

- Encourage critical thinking about ethical leadership.
- Demonstrate how different decisions reflect leadership values.
- Create an engaging learning experience through interactive scenarios.
- Collect survey responses for educational analysis.
- Apply web development and cloud database technologies to a practical project.

## ✨ Key Features

### 1. Interactive Ethical Scenarios
Participants answer three ethical dilemmas, each containing four possible responses.

### 2. Automated Scoring
The application evaluates participants' selections and calculates a score between 0 and 3.

### 3. Animated Leadership Results
Participants receive one of two outcomes:

😇 **Ethical Leader:** Score of 2–3.

😈 **Evil Leader:** Score of 0–1.

These classifications are designed for educational engagement rather than professional psychological assessment.

### 4. Firebase Integration
Survey responses are stored using Google Firebase Cloud Firestore.

Recorded information includes:
- Selected answers
- Ethical leadership score
- Leadership classification
- Submission timestamp

### 5. Anonymous Authentication
Firebase Anonymous Authentication enables participants to submit responses without creating a traditional account.

### 6. Mobile-Friendly Participation
The survey can be accessed using a web browser on compatible devices.

Participants can also access the application through a QR code linked to the live website.

## 🧠 How the Survey Works

**Step 1:** Open the application.

**Step 2:** Read each ethical leadership scenario.

**Step 3:** Select one response for each scenario.

**Step 4:** Submit the completed survey.

**Step 5:** The application calculates the ethical leadership score and saves the response.

**Step 6:** An animated leadership classification is displayed.

## 📊 Scoring System

Each scenario has one response designated as the ethical choice.

| Ethical Choices | Classification |
|---|---|
| 0 | 😈 Evil Leader |
| 1 | 😈 Evil Leader |
| 2 | 😇 Ethical Leader |
| 3 | 😇 Ethical Leader |

**Disclaimer:** The scoring system is a simplified educational exercise. It should not be used to make real-world judgments about an individual's character or leadership competence.

## 🔐 Data and Privacy

The application uses Firebase Anonymous Authentication and Cloud Firestore.

It does not require participants to enter their names or email addresses.

Survey responses are stored for educational purposes.

Anonymous authentication does not guarantee complete anonymity, and participants should avoid entering personal information.
